# Модель угроз (STRIDE, v1)

## Активы
Целостность Windows и игр; аккаунты игроков (риск блокировки античитом); журнал отката; приватность данных о ПК; лицензионный ключ.

## Границы доверия
1. Пользователь ↔ FramePilot.exe (medium integrity).
2. FramePilot.exe → PresentMon (elevated по UAC, фиксированные аргументы).
3. FramePilot.exe → PrivilegedHelper (elevated по UAC, один глагол).
4. Файлы игр/Steam/Riot — недоверенные входные данные (только чтение, парсинг).
5. CSV PresentMon и импортируемые CSV — недоверенные входные данные.

## Угрозы и меры
| Угроза | Мера |
|---|---|
| Подмена журнала для записи в произвольный ключ реестра | `RegistryTargetResolver` принимает только allowlist HKCU; тест `RegistryAllowlist_RejectsOtherLocations` |
| Инъекция аргументов PresentMon | Имя процесса `[A-Za-z0-9._-]`, абсолютный путь `.csv`, длительность 10–1800 с; аргументы строятся кодом |
| Эскалация через helper | Нет параметров кроме глагола из allowlist; описание точки восстановления фиксировано; нет shell; нет долгоживущего IPC |
| GPU-предпочтение для чужого exe | `SetHighPerformanceGpuAction.ValidateExecutablePath` — только `cs2.exe` и `VALORANT-Win64-Shipping.exe`, абсолютный путь |
| Вредный «твик» в каталоге правил | Правила — код в сборке; загрузка правил/команд из сети отсутствует |
| Порча журнала при сбое питания | SQLite WAL + synchronous=FULL; запись до изменения; `Recover()` при старте |
| Перезапись пользовательских настроек при откате | Обнаружение конфликта, перезапись только после подтверждения |
| Античит | Нет инъекций, чтения памяти, изменения бинарников, макросов, драйвера ядра; телеметрия через ETW. Это снижает риск, но **не** даёт права заявлять «100% safe» или «одобрено Riot/Valve» |
| Отключение защит ради FPS | Запрещено: Defender, Firewall, Update, Secure Boot, TPM, HVCI/VBS не изменяются ни одним действием |
| XSS в HTML-отчёте (название GPU, имя процесса) | Всё экранируется `WebUtility.HtmlEncode`; тест `Html_MarksDemoData_AndEscapesContent` |
| Подделка лицензии | ECDSA P-256 / SHA-256, в приложении только публичный ключ; тесты на подмену payload и чужой ключ |
| Утечка данных | Нет сетевых вызовов в приложении; экспорт только по действию пользователя |
| Две копии приложения пишут журнал | Именованный mutex `Local\FramePilot.SingleInstance` |

## Явно запрещено в коде (v1)
DLL injection, чтение памяти игры, изменение бинарников, обход античита, макросы, kernel driver, отключение Defender/Firewall/Update/Secure Boot/TPM/Memory Integrity, BCD/HPET/таймеры, массовое отключение служб, отключение pagefile, «очистка RAM», разгон/андервольт, изменение BIOS, установка драйверов, очистка шейдерного кэша, закрытие программ пользователя, сетевые «твики», произвольный PowerShell.

## Остаточные риски
- Античит может изменить политику в отношении любых сторонних программ. Совместимость проверяется тестами на реальных аккаунтах перед каждым релизом (см. TEST_PLAN).
- Подписание релизных сборок требует сертификата Authenticode (не входит в репозиторий).
