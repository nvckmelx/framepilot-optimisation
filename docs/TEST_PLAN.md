# План тестирования

## Автоматические (xUnit, `dotnet test`)
| Набор | Что покрывает |
|---|---|
| MetricTests | Формулы FPS, P99 (nearest-rank), 1% low ≠ 1000/P99, медиана, скачки, пороги, отбрасывание невалидных кадров, unavailable вместо 0 |
| ComparisonTests | ≥3 прогонов, непересекающиеся диапазоны, шум, регрессия, разные условия, смесь демо/реальных |
| ChangeEngineTests | Журнал до изменения, проверка чтением, идемпотентность, повторный откат, конфликт и force, компенсирующий откат, recovery после сбоя (Prepared/RollbackPending), recovery не пишет в систему, сохранение токенов DX-строки, отказ для чужого exe, preview без записи |
| DxPreferenceStringTests | Разбор и правка строк DirectX, allowlist реестра |
| PresentMonCsvTests | Колонки v1/v2, NA, обрезанная строка, фильтр процесса, выбор swap chain, кавычки |
| PresentMonRunnerTests | Только документированные аргументы, валидация имени/пути/длительности |
| VdfTests | libraryfolders.vdf, appmanifest |
| RuleTests | Метаданные всех правил, срабатывание/несрабатывание каждого правила, без догадок, Reflex только NVIDIA, VALORANT-правила, GPU/CPU-упор, цель «задержка», демо игнорируется |
| StorageTests | Round-trip снимка с unavailable, разделение демо, журнал, engine поверх SQLite, удаление данных без журнала |
| LicenseTests | Подпись, чужая машина, срок, подмена payload, чужой ключ, мусор |
| ReportTests | JSON round-trip, определения метрик, демо-пометка и HTML-экранирование, вердикт сравнения |

## Ручная проверка на Windows 11 x64 (перед каждым релизом)
1. Запуск без прав администратора; заголовок окна тёмный; RU/EN переключаются на лету.
2. «Проверить и настроить»: заполнены CPU/GPU/RAM/диски/мониторы; недоступные поля серые с подсказкой причины.
3. Игры: CS2 найден через Steam (в т.ч. на второй библиотеке), VALORANT — через Riot Client.
4. Сессия 60 с в CS2 (Practice/Offline): UAC только для PresentMon; кадры > 0; график; Ctrl+Shift+F10 останавливает досрочно.
5. То же для VALORANT в Range.
6. Импорт CSV, записанного PresentMon вручную.
7. Применение (с Pro-ключом тестовой пары): план показывает до/после; в реестре значения изменились; История — «Применено и проверено».
8. Вручную изменить `AutoGameModeEnabled` → «Восстановление» показывает расхождение; откат спрашивает подтверждение.
9. Убить процесс FramePilot во время применения (Диспетчер задач) → при запуске «Проверка при запуске» сообщает результат.
10. «Вернуть всё как было» → все значения восстановлены (в т.ч. удалены значения, которых не было).
11. Точка восстановления: создана / корректное сообщение при лимите 24 ч или выключенной защите.
12. Экспорт JSON/HTML; демо-режим помечен везде.
13. Масштаб 100/150/200%, только клавиатура (Tab/Space/Enter).
14. Античит: 3 матча CS2 (VAC) и 3 матча VALORANT (Vanguard) с запущенным FramePilot и записью сессии — без предупреждений. Результат фиксируется в журнале релиза; без этого никакие заявления о совместимости не делаются.

## Что нельзя проверить в CI
UI-сценарии, реальные игры, античит, UAC, реальные значения железа — только ручной прогон на Windows.
