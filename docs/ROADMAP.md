# Дорожная карта

## v1.0 (этот репозиторий)
Инвентаризация, обнаружение игр, запись PresentMon, метрики, 18 правил, план/применение 3 обратимых действий HKCU, журнал и откат, восстановление после сбоя, точка восстановления через helper, сравнение прогонов, JSON/HTML-отчёты, RU/EN, демо-режим, офлайн-лицензии, установщик.

## v1.1 — качество
- Подпись Authenticode релизов и установщика.
- Автоматическое обновление (подписанный манифест, проверка подписи).
- Расширенный тестовый парк (AMD/Intel GPU, гибридные системы, 2+ монитора, HDR/VRR).
- Сбор согласованных обезличенных отчётов (opt-in).

## v1.2 — правила
- HAGS: протокол A/B и правило только по результатам измерений.
- Оверлеи и фоновая запись (Game Bar, Discord, Steam) — диагностика влияния по сессиям «с/без».
- Анализ VRR/G-SYNC/FreeSync и рекомендуемого лимита FPS по замерам, а не по формуле.
- Чтение версии и пресетов CS2 из cs2_video.txt с интерпретацией после проверки ключей.

## v2.0
- Ноутбуки (MUX, режимы питания OEM, батарея) — отдельный набор правил.
- Новые игры — по одной, с правилами и тестами.
- B2B: компьютерные клубы, сборщики (пакетный отчёт).
- Опционально: LLM-объяснение уже сформированного структурированного отчёта (не выполняет команд).

## Не планируется
Драйвер ядра, BIOS-тюнинг, разгон, «очистка RAM», сетевые «ускорители», отключение защит.
