# FRAMEPILOT — PRD (v1.0)

> Рабочее название. Юридическая доступность товарного знака не проверялась.

## Обещание продукта
FramePilot анализирует конфигурацию и поведение ПК в игре, выявляет вероятные причины нестабильного FPS и задержек, объясняет их, применяет только поддерживаемые обратимые изменения после подтверждения и помогает проверить результат повторным измерением.

**Не обещаем:** «+N FPS всем», «нулевую задержку», ускорение интернета реестром, абсолютную совместимость с античитами, полную диагностику каждого компонента.

## Аудитория v1
Владельцы настольных игровых ПК на Windows 11 x64, играющие в CS2 и VALORANT. Ноутбуки — отдельный будущий набор правил.

## Главный сценарий (Measure → Diagnose → Explain → Approve → Apply → Verify → Compare → Rollback)
| Шаг | Экран | Что происходит |
|---|---|---|
| 1. Проверка ПК | Обзор → «Проверить и настроить» | Read-only инвентаризация (WMI/CIM, Win32, реестр — только чтение), 5 с наблюдения фоновой нагрузки |
| 2. Игровая сессия | Анализ сессий | PresentMon пишет CSV для выбранной игры; длительность 60–300 с; остановка Ctrl+Shift+F10 |
| 3. Диагноз | Рекомендации | Правила выдают симптом, доказательства, причины, уверенность, действие, ограничения, способ проверки |
| 4. План | Рекомендации → «Посмотреть план» | Точный список: ключ, текущее значение → новое значение |
| 5. Применение | «Применить» (Pro) | Журнал до изменения, запись, проверка чтением, компенсирующий откат при частичном сбое |
| 6. Сравнение | Анализ сессий | ≥3 прогона «до» и ≥3 «после»; изменение засчитывается только при непересекающихся диапазонах |
| 7. Откат | История / Восстановление | Бесплатно; конфликт при ручном изменении — только с подтверждения |

## Категории рекомендаций
1. **Можно применить автоматически** — есть проверенное типизированное действие (v1: Game Mode, оптимизация оконных игр, GPU-предпочтение для exe игры). Всё в HKCU, без прав администратора.
2. **Требует решения пользователя** — частота монитора, Reflex, Multithreaded Rendering, XMP/EXPO, схема питания, фоновые программы, место на диске.
3. **Только диагностика** — упор в GPU / CPU-движок, скачки времени кадра, ограничение FPS, один модуль памяти, игра на HDD, возраст драйвера, требования Vanguard.

## Данные и честность
- Отсутствующее значение = `unavailable` + причина + источник + время. Никаких подстановок.
- Демо-режим: отдельное хранение, постоянный баннер, пометка в отчётах, запись и применение отключены.
- FPS ≠ задержка. «PC latency» — только когда её сообщает PresentMon; полная click-to-photon задержка не заявляется.

## Монетизация (гипотеза)
| Тариф | Состав |
|---|---|
| Free | Инвентаризация, диагностика, запись сессий (история до 20), рекомендации, экспорт, **откат всего** |
| Pro (24,99 €/12 мес, 1 ПК) | Применение в один клик, неограниченная история, новые правила в период лицензии |
| Founders (14,99 € первый год) | Как Pro |

Лицензия — офлайн-ключ ECDSA P-256, привязан к коду компьютера (`fp-license`).

## Нефункциональные требования
- Основное приложение работает без повышения прав (`asInvoker`).
- Local-first: без регистрации, без облака, без телеметрии.
- RU/EN с переключением на лету; клавиатурная навигация с видимым фокусом; Per-Monitor DPI v2.

## Метрики продукта
Доля завершивших первый анализ; доля прошедших игровой тест; доля ПК с применимыми рекомендациями; конверсия; возвраты; обращения/100 клиентов; доля успешных откатов; доля сравнений с подтверждённым улучшением; **доля пользователей без улучшения (не скрывается)**.
